## Description

La boule de Noël est un item exclusif des #blocs/christmas-gift. Il faut impérativement ouvrir un cadeau de Noël pour en obtenir. La probabilité d'obtenir cet item est de 4 %.

La potion d'invisibilité vous permet de devenir invisible pendant vos combats, ce qui facilite votre back dans les situations tendues.

## Caractéristique 

- ``Durée de l'effet`` : 2.5 secondes
